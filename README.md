# sumo-robot

Code and CAD for my sumo robots, collected from several competition seasons.

```
sumo-robot/
├── early-versions/   SumoBot, SumoBot_4.0, Sumo_ArduinoIDE (first designs, plus Scratch/test sketches)
├── 2025/             sumo, sumo2, sumo_taoyuan, sumobeijing, theUltimateSumobot
├── 2026/             PID_Sumo, Sumo, Sumo2.0, sumoTCRV2 ... sumoTCRV5
└── chassis/          STL files for the chassis body, cover and shovels
```

Each folder is an Arduino sketch: open the `.ino` file in Arduino IDE.
